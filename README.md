# Dashboard de anuncios de vehículos

Aplicación web interactiva para explorar datos de anuncios de vehículos.

El dashboard incluye:

- Un histograma que muestra la distribución de los precios anunciados de los vehículos.
- Un gráfico de dispersión que muestra la relación entre el año del modelo y el precio anunciado.
- Una casilla de verificación interactiva que permite excluir los precios anunciados por encima del percentil 99, reduciendo el impacto visual de los valores extremos y facilitando el análisis de la distribución principal de los datos.

## Tecnologías utilizadas

- Python
- Pandas
- Plotly
- Streamlit

## Conjunto de datos

El conjunto de datos contiene anuncios de vehículos con información como precio, año del modelo, modelo, condición, kilometraje, tipo de combustible, transmisión, tipo de vehículo y fecha de publicación del anuncio.
